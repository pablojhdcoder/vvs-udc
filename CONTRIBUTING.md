# Guía de contribución

## Convenio de commits

Utilizaremos Conventional Commits.

### Formato

`tipo(ámbito): descripción`

### Tipos

- `feat`: nueva funcionalidad
- `fix`: corrección de errores
- `docs`: documentación
- `style`: formato
- `refactor`: refactorización
- `test`: tests
- `chore`: mantenimiento
- `build`: compilación/dependencias
- `ci`: integración continua
- `perf`: rendimiento

### Ejemplos

- `feat(auth): añadir login`
- `fix(api): corregir respuesta 404`
- `docs: actualizar README`
- `test(users): añadir tests de usuarios`
